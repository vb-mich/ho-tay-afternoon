# Hồ Tây · An Afternoon in Hanoi

A cozy 2.5D browser game set along the Thanh Niên promenade and around Trấn Quốc Pagoda.

## Playtest

[Open the game](https://vb-mich.github.io/ho-tay-afternoon/)

- Move with WASD, the arrow keys, the touch pad, or click or tap a path.
- Scroll over the game or pinch with two fingers to zoom. Use **+** or **−** for keyboard zoom and **0** to reset.
- Press **E** near a marked person or landmark to interact. Selecting a marker walks you there.
- Press **J** to open the journal and **M** to open the map. The journal saves on the current browser and device.

The walk has three main stops and an optional noticeboard.

## Run locally

From this directory, run `python3 -m http.server 8000` and open `http://localhost:8000`. The game is static and uses native browser modules.
